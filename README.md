# Sales-Dashboard

An interactive Sales Analytics Dashboard built with React and Recharts that provides real-time business insights through dynamic visualizations, KPI metrics, filtering options, and CSV data import functionality.

## 🚀 Features

### 📈 Dashboard Analytics
- Total Revenue Tracking
- Units Sold Analysis
- Gross Profit Calculation
- Profit Margin Monitoring

### 📊 Interactive Visualizations
- Revenue by Category (Pie Chart)
- Revenue by Region (Bar Chart)
- Monthly Revenue Trends (Area Chart)
- Revenue vs Profit Comparison (Line Chart)
- Monthly Units Sold Analysis
- Top Products by Revenue
- Regional Performance Comparison

### 🔍 Advanced Filtering
Filter dashboard data by:
- Region
- Product Category
- Product Name

### 📂 CSV Import Support
Users can upload their own CSV files to:
- Replace sample data
- Generate instant analytics
- Visualize custom sales datasets

### 🔄 Data Management
- Import custom datasets
- Reset to sample dataset
- Real-time dashboard updates

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Kavya061206/Sales-Dashboard.git
```

Navigate to project directory:

```bash
cd Sales-Dashboard
```

Install dependencies:

```bash
npm install
```

Install Recharts:

```bash
npm install recharts
```

Run the development server:

```bash
npm start
```

Application will open at:

```text
http://localhost:3000
```

## 📄 CSV Format

The dashboard supports CSV files with the following columns:

| Column | Description |
|----------|-------------|
| date | Transaction date |
| product | Product name |
| category | Product category |
| region | Sales region |
| units | Units sold |
| revenue | Revenue generated |
| cost | Product cost |

Example:

```csv
date,product,category,region,units,revenue,cost
2024-01-05,Wireless Headphones,Electronics,North,42,5040,2100
2024-01-08,Running Shoes,Apparel,South,78,7020,3120
```
